## 📄 CareerOS AI — Build. Showcase. Get Hired.

CareerOS AI is an all‑in‑one career operating system that helps you create ATS‑optimized resumes, build professional portfolios, match with jobs, and accelerate your career all powered by AI.

## 🚀 Features

| Module | Description |
|--------|-------------|
| **Resume Builder** | Structured editor with live preview, multiple templates, AI rewrites, and PDF export. |
| **Portfolio Builder** | Drag‑and‑drop sections, 23+ content blocks, custom domains, and responsive themes. |
| **ATS Optimizer** | Real‑time scoring, keyword suggestions, and formatting checks to pass applicant tracking systems. |
| **AI Career Coach** | Personalized advice based on your resume and goals—reviews, roadmaps, and interview drills. |
| **Job Matching** | Scored job recommendations, skill‑gap analysis, and an integrated application tracker. |
| **Cover Letter Generator** | Role‑specific letters generated from your resume and target company language. |
| **LinkedIn Optimizer** | Enhance your profile with AI‑powered headline and summary suggestions. |
| **Analytics Dashboard** | Track portfolio visits, resume views, and application funnel metrics. |

## 🛠️ Tech Stack

| Category | Technology |
|----------|------------|
| **Frontend** | React 19, TypeScript, Tailwind CSS, Motion (Framer Motion) |
| **Routing** | React Router v7 (client‑only) |
| **State Management** | React Context + custom hooks |
| **UI Components** | Radix UI primitives + shadcn/ui |
| **Data Fetching** | TanStack React Query (for future API integration) |
| **Build Tool** | Vite 8 |
| **Deployment** | Vercel (recommended) |


## 📦 Installation

| Command | Description |
|---------|-------------|
| `npm run dev` | Starts Vite dev server with HMR. |
| `npm run build` | Builds the app for production. |
| `npm run preview` | Previews the production build locally. |
| `npm run lint` | Runs ESLint. |
| `npm run format` | Formats code with Prettier. |
